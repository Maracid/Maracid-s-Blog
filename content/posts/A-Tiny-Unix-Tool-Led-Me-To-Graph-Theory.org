* The Graph Theory tool
This tool is used to count graph components, and before this, I had never encountered graph theory but I seized this opportunity to learn about it. We can do a simple test
#+begin_src dot
graph G {
    A -- B;
    B -- C;
    D -- E;
    F;
    }
#+end_src

We will save this file as graph.dot and then =gc -a graph.dot= the output looks like this:

#+begin_src bash
6       3       3       1 G (graph.dot)
#+end_src

The simple options of gc include

#+begin_quote
-n Count nodes.
-e Count edges.
-c Count connected components.
-a Count all. Equivalent to -encC
#+end_quote

And the output just means

| Number | Meaning |
|--------+------|
| 6      | Nodes |
| 3      | Edges |
| 3      | Connected components |
| 1      | Clusters |

2. What is nodes and edges?
Many things in the real world can be abstracted into a network
- Every city is a node
- The road connecting two cities is an edge
- Everyone is a node
- The relationship of two people is an edge
*A Node is object and edge is relationship of two objects*
